# LunaPanel action-names.txt
#
# Complete list of every Frontier-defined bindable action element name found
# in a real, currently-installed Elite Dangerous keybindings file (a
# Custom.<major>.<minor>.binds file), extracted using the same "action" shape
# rule BindingsFile.Parse already applies in production: a root child element
# is an action only if it carries a <Primary> and/or <Secondary> child.
#
# This is a factual token vocabulary - Frontier's own action identifiers,
# nothing more - the same category as the DIK_* DirectInput scancode
# constants LunaPanel already treats as fair game to encode directly, and
# categorically different from the EDHM-UI theme files that were scrapped
# from this project's fixtures for being another party's authored creative
# content. No keys, no devices, no bound values, and no user-identifying
# data of any kind appear below: only the bare element names themselves,
# one per line, sorted.
#
# Exists so LunaPanel.Tests can prove every curated catalogue action name
# (see src/LunaPanel.Server/definitions/catalogue.json) is a real Frontier
# element name, rather than a typo that would ship a permanently dead
# catalogue entry with nothing in the vocabulary to catch it.
